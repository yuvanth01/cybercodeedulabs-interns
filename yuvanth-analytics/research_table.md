| SSH Brute Force      | An attacker repeatedly tries different passwords to gain SSH access. Usually automated using scripts or bots.          | auth.log, secure log                          | Many failed SSH logins from the same IP within a short time                | T1110.001 (Password Guessing)                 | Count failed login attempts per IP per minute; alert if attempts > 10. ([MITRE ATT&CK][1])            |
| Port Scan            | An attacker checks many ports to discover running services and open entry points. Often performed before exploitation. | firewall logs, syslog, IDS logs               | Same IP connects to many different ports in a short period                 | T1046 (Network Service Discovery)             | Count unique destination ports per source IP; alert if ports scanned > threshold. ([MITRE ATT&CK][2]) |
| HTTP Probe           | An attacker requests unusual URLs to find vulnerabilities, admin panels, or hidden files.                              | nginx access.log, apache access.log           | Many requests to uncommon paths such as `/admin`, `.env`, `phpmyadmin`     | T1595.002 (Vulnerability Scanning)            | Match suspicious URLs using regex and count requests per IP. ([Reddit][3])                            |
| Firewall Block       | Traffic is blocked because it violates firewall rules or targets restricted ports.                                     | firewall.log, syslog                          | Repeated denied connections from same IP                                   | T1562 (Impair Defenses)                       | Count firewall deny events per IP; flag excessive blocked attempts.                                   |
| Process Anomaly      | A process behaves differently than normal, such as high CPU usage or unusual execution.                                | syslog, audit.log, process monitoring logs    | Unknown process consuming excessive resources or spawning unusual children | T1055 (Process Injection)                     | Compare process behavior against baseline; flag outliers. ([Reddit][4])                               |
| Data Exfiltration    | Sensitive data is transferred out of the network without authorization.                                                | proxy logs, network logs, firewall logs       | Large outbound transfers to external destinations                          | T1041 (Exfiltration Over C2 Channel)          | Calculate outbound bytes per host; alert when transfer exceeds threshold.                             |
| Lateral Movement     | An attacker moves from one system to another after gaining initial access.                                             | auth.log, Windows Event Logs, SMB logs        | Same account logs into multiple hosts within a short period                | T1021 (Remote Services)                       | Track user logins across hosts; detect unusual host-to-host movement.                                 |
| Privilege Escalation | An attacker gains higher permissions such as root or administrator access.                                             | auth.log, sudo logs, audit.log                | Unusual sudo usage or privilege changes                                    | T1068 (Exploitation for Privilege Escalation) | Detect sudden privilege changes or repeated sudo failures followed by success.                        |
| SQL Injection        | Malicious SQL commands are inserted into web inputs to access or modify databases.                                     | web server logs, database logs                | Requests containing `' OR 1=1`, UNION SELECT, DROP TABLE                   | T1190 (Exploit Public-Facing Application)     | Use regex to detect SQL keywords and suspicious query patterns.                                       |
| DDoS Flood           | Many systems overwhelm a server with massive traffic, making it unavailable.                                           | nginx access.log, firewall logs, network logs | Extremely high request rate from many IPs                                  | T1498 (Network Denial of Service)             | Count requests per second; alert when rate exceeds baseline.                                          |
| DNS Tunnel           | DNS queries are abused to secretly transfer data out of the network.                                                   | DNS logs, resolver logs                       | Long encoded DNS queries with high frequency                               | T1071.004 (DNS Protocol)                      | Measure DNS query length and frequency; flag encoded-looking domains.                                 |
| Ransomware Behavior  | Malware encrypts files and demands payment for decryption.                                                             | syslog, audit.log, EDR logs                   | Large numbers of file modifications or renames in a short time             | T1486 (Data Encrypted for Impact)             | Monitor file operations; alert on mass encryption or file extension changes.                          |
