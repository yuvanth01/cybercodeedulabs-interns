| SSH Brute Force | An attacker repeatedly tries many username and password combinations to gain access to a server through SSH. These attempts are usually automated and happen very quickly. | `/var/log/auth.log`, `/var/log/secure`, SSH logs             | Multiple "Failed password" entries from the same IP within a short period (e.g., more than 10 failed logins per minute). | T1110.001 (Password Guessing)     | Parse `auth.log`, extract IP addresses using regex, count failed login attempts per IP, and flag IPs exceeding a threshold.                         |
| Port Scan       | An attacker probes multiple ports on a target system to discover open services and potential entry points. It is often the first step before launching an attack.          | Firewall logs, IDS/IPS logs, syslog, network monitoring logs | One source IP attempting connections to many different ports in a short time (e.g., 20+ ports within 1 minute).          | T1046 (Network Service Discovery) | Parse network/firewall logs, track destination ports contacted by each source IP, count unique ports, and alert when the count exceeds a threshold. |
